Задание 4: "Выбор типа данных" Для каждой из следующих задач выберите наиболее подходящий тип данных из пройденных (int, float, str, bool, list, tuple, set, dict) и кратко объясните свой выбор:

1. Хранение текущего количества студентов в группе. 
   **int** — Целое значение, не может быть пол студента.
2. Хранение температуры в градусах Цельсия (например, 23.5). 
   **float** — Дробное.
3. Хранение логина пользователя (например, "ivanov_ivan"). 
   **str** — собственно, строчка.
4. Хранение информации о том, включено ли уведомление (да/нет). 
   **bool** — Логическое значение.
5. Хранение списка любимых фильмов. 
   **list** — Может изменяться, в некоторых сценариях может быть важен порядок.
6. Хранение координат точки в 2D пространстве (x, y), которые не должны изменяться после задания. 
   **tuple** — Неизменяемо, важен порядок.
7. Хранение уникальных ID товаров в корзине покупок. 
   **set** — Важна уникальность.
8. Хранение соответствия между названием страны и её столицей. 
   **dict** — сопоставление ключа и значения.
